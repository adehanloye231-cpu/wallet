# MyWallet Simulator

MyWallet Simulator is a digital wallet application built with **Spring Boot** for the backend. The project simulates common wallet operations such as user account management, deposits, withdrawals, balance tracking, and money transfers.

The application demonstrates how a backend system can manage financial transactions using **Java, Spring Boot, REST APIs, and PostgreSQL**. It is designed as a learning project for understanding backend development, database integration, API development, and transaction-based applications.

### Features

* User wallet/account management
* Deposit and withdrawal simulation
* Balance management
* Money transfer between wallets
* Transaction tracking
* RESTful API endpoints
* PostgreSQL database integration
* Backend validation and error handling

### Technologies Used

* **Java 21**
* **Spring Boot**
* **Spring Data JPA**
* **PostgreSQL**
* **Maven**
* **REST API**
* **Git & GitHub**

> **Note:** This is a simulator/learning project and does not process real financial transactions.
